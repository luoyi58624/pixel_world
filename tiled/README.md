# 双桥关

64×48 格、16×16 像素图块的原创关卡布局。河流将四座城分布在两岸，北桥与南桥构成两条独立的过河通道。地图素材复用项目已有的 NES 地形资源，城池名称、路线、关卡布局和阵营配置为本次设计。

在 Tiled 中打开 `双桥关.tmx` 即可编辑。地图通过 `terrain.tsx` 引用 `../assets/images/terrain.png`，请保留相对目录关系。

## 图层

1. 地形：草地、海岸、月牙湖与主河道。
2. 道路：两岸主路和两座桥。
3. 山地：用于围合地形的山体。
4. 树林：道路之外的林地。
5. 建筑：青岚城、松风堡、双桥关、南泽城及补给点。
6. 城池信息：可选中修改 cityId、owner、displayName。
7. 出生点与补给：供游戏逻辑读取的对象。
8. 行军路线：折线路径参考。
9. 碰撞区域：水域与山地的阻挡矩形。
10. 地名：可独立隐藏的文字标注。

第 6–9 层默认隐藏，点击图层旁的眼睛可查看和编辑。当前地图是独立 Tiled 关卡，还没有接入 Flutter 地图选择器。

`双桥关.tmj` 是 Tiled 原生 JSON 导出；`双桥关-preview.png` 由 Tiled 重新读取 TMX 后渲染；`validation.json` 记录连通性及保存校验结果。

## 重生成

使用本机 Tiled 1.11.2 的官方 JavaScript 接口创建地图：

```powershell
& 'C:\Program Files\Tiled\tiled.exe' --evaluate .\create_twin_bridges.js
```

重生成会覆盖本目录中的生成文件。手动编辑地图前，可以先另存为其他名称。
