# 欠薪离职验收（2026-09-14）

月结收入到账后优先支付强将月俸，不能付清的将领立即离职，按内政等额返还金币，再继续向后发俸。强弱依次按战斗力、最大生命、士气和固定名册顺序比较。主角固定免薪，旧存档续玩同样生效，历史回放保留原工资。

离职统一清理行军、随军兵员和 AI 任务。交战将领离职不会生成战败奖励：攻方离职释放攻城队列，守方离职由下一名守将接替，双方离职结束战斗，野战幸存者恢复原行动。最后一名守将离职后可正常占领空城，不提前改变其他国家的当月收入。

账单增加 `salaryDue`、`departureIncome`、`departedHeroes`，`salary` 表示实付工资；旧账单恢复使用兼容默认值。日志增加 `heroDeparted`，返款已包含在 `monthSettled` 中，对账不能重复计入。补充 `treasuryCleared` 事件记录既有亡国清库规则，胜方不继承金币。
