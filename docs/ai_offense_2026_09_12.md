# 国家 AI 进攻调度优化

本次只调整决策顺序和部队任务。城防攻击仍为 1/3/5/8/10，英雄、武器、经济、士气、AI 配置阈值和静态战力估算公式均保持原值。

## 当前行为

- `assessRaid` 先判断完整攻势与编队需要，无法组成完整攻势时才使用既有单轮消耗门槛。裸装与伤重限制继续生效。
- `raidTeamSize` 按当前将领、装备报价、国库、守军和抵达间隔扩充轮攻，不再要求第三年才允许扩充。原人数上限、战力筛选与预算公式不变；全国强攻名额的额外招募仍保留原条件，不因提前组队而无目标扩招。
- 在外远征军耗尽武器后，使用当前实际生命、随军兵员和下一位守将重新判断。仍占优或目标为空城则保持进攻；需要补装时，允许越过原行军承诺和短时避让状态，安排安全友城整备。
- 无安全补装地点时使用现有扎营、待命流程，后续继续复查。已经交战、撤退锁定或不能合法移动的部队不被强制拉走；不能远程补兵或领取武器。

所有判断均为现有公开观察上的有界静态计算，不预演战斗、抽取随机胜率或读取未来结果。正式运行继续使用常驻 Isolate / Dedicated Worker。

## 对照结果

三张实际地图 × 种子 101/223/337，每局 600 游戏秒；全部国家由 AI 控制，真实常驻 Isolate 后台按模拟器约定等待完成。两批 JSON 输入相同；相关配置与估算文件另以 SHA-256 核验未变。

|---|---:|---:|
| 城池易主次数 | 26 | 36 |
| 将领阵亡人次 | 1031 | 963 |
| 出征次数 | 934 | 1105 |

| 危险守城超员采样 | 0 | 0 |

占城次数增加约 38.5%，阵亡人次减少约 6.6%；出征次数包含补装后再次出征，不等于去重将领数。多人安排包括 65 次双人和 3 次三人任务组，不能据此认为所有成员都必然抵达或获胜。

三张地图的易主次数分别为 9→10、6→14、11→12；阵亡分别为 356→337、330→288、345→338。新日志包含 173 次回城补装安排，另有 66 次无安全补装地点时的停止推进安排。

改派任务由 88 次增加到 376 次，其中距上一任务不足七秒的改派由 24 次增加到 51 次。补装和回城增加了调度活动，不能把这些数字全部视为无意义反复改令；但这也是后续应继续观察的成本。所有局达到观察时限、没有统一；此结果仅覆盖开局十个月，不证明所有地图、种子和后期局势必然改善，也不能代替手机性能测试。
