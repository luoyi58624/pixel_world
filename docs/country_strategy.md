# 国家进攻与防御决策

各城共享国家国库与武器库存。开局取消八秒等待，从首个逻辑帧开始逐国决策，每帧最多处理一个国家；首轮结束后按原五秒周期错峰经营。玩家将领仍由用户指挥。

## 防御优先

检查本国城池附近的敌军、其行军目标及路线，城内正在交战也视为威胁。发现来敌后停止本国新的外攻，优先为受威胁城池升级、招募将领、补足国家兵员。守军不能使用武器，AI 不为守家购买武器。所有行为仍受金币、粮草预留、招募容量和月度次数限制。最多处理当次威胁最高的两座城。

## 选择与筹备目标

所有电脑国家默认优先扩张弱国。国力由城防、全部存活将领及储备／随军兵员计算；候选城池再结合本地守军强度、实际行军成本与仇恨加权随机选择。不再单纯因为某国城池多而优先进攻它，玩家采用同一套国力比较。

每座城从 campaign_config.json 的 worlds[].cities[].requiredGarrison 读取最低留守将领数，默认两位，与等级、升级或易主无关；人数不足时不会凭空生成将领。对所有多余将领逐一寻找可取胜且能供养的目标，优先分散到不同可攻目标，没有其他可行目标时可以同城排队，不再只派一人或受四人总出征上限限制。新招募形成多余将领后同次决策即可出发。

单军扩张使用不需要牺牲将领的方案；无法单独攻下的目标，继续以最多四名将领组成一支轮攻队，若裸装预计出现战败，则尝试增加武器以减少损失与所需队伍，高防御轮攻至少预备有效装备。将领不足时先招募，只在招募门槛阻挡时升级扩充名额。人数和装备足够、资金不够时保留目标积蓄金币，不先零散派出准备不足的队伍。附近有更容易且现有资金能承担的目标时转攻该目标；当前最强四人编队也无法取胜时评估其他目标，不无限招募无法上场的第五人。

发动前统一检查整支队伍的武器费用、兵员费用及包含排队的粮草预算，资金充足后从国家库取用，不足部分按价购买，再逐将带走，避免重复使用同一库存。国家库不限总量，每将最多三件，回城将剩余武器归库。使用现有城下排队规则逐将进场。进攻和野战过程中电脑会使用武器，只有高级将领生命严格低于最大值四分之一、安全武器耗尽且实际战况胜算渺茫时才考虑撤退。断粮后的旧营地优先回友城整备，撤退部队继续原路返回，不被经营逻辑改派。

这是一套新增的可调整策略评估，不是从 ROM 提取的原版国家 AI，也不保证每次预测都获胜：对方可能升级、招募、增援，战斗和撤退仍含随机性。

## 开销控制

- 首次每帧启动一个国家，随后每国平均五秒决策一次；一次固定逻辑帧最多处理一个国家。
- 每次只为当前国家建立驻军、归属和威胁快照；每名拟出征英雄的目标粗筛后最多精算三条路线，装备方案在各候选间复用。
- 路线耗时按出发坐标、目标城与等级缓存，最多 256 条；城堡变化会使用新键，长期游戏不会无限增加缓存。
- 单支联合轮攻预测最多四名将领，全面扩张可以分派更多支部队；使用算术估计，不逐帧模拟假想战斗。武器由玩家与电脑共用的开场、碰撞事件触发：开场自动一件，每次拼杀后独立判定 50%，无事件时不掷骰。
- 多张正式地图的回归测试检查错峰次数、路线计算数量、金币、兵员与英雄唯一性。模拟耗时是无渲染逻辑测试结果，不能当作整机画面帧率。

每支敌军实际抵达城下时，被侵略国对来犯国的仇恨增加 20。同一支出征军对同一国家只记录一次，排队、换守将及逐帧更新不重复记账；野战双方各增加 20。仇恨最多 100，不自动衰减，满值提供三倍国别目标权重。它会提高反击倾向，但不会绕过守家、胜算与粮草检查。

留守数在玩法 JSON 中逐城配置。其他参数位于 `GameConfig`：`countryAiInitialDelay`、`countryAiInterval`、`countryAiStrengthScale`、`countryAiWeaknessPower`、`countryHatredPerAttack`、`countryHatredMaximum`、`countryHatredWeightPerPoint`，以及原有预算、候选数量和缓存上限。排队粮草包含仍在路上且预计先到的军队。
