# 国家进攻与防御决策

每国保持一个锁定目标和阶段：守家、筹备、积蓄资金、执行进攻。各城共享国库、库存与同一进攻计划，已经派出的队伍不会在下一次决策又重复配一批。

## 防御优先

检查本国城池附近的敌军、其行军目标及路线，城内正在交战也视为威胁。发现来敌后停止本国新的外攻，优先为受威胁城池升级、招募将领、补足国家兵员并给可用守军配武器。所有行为仍受金币、粮草预留、招募容量和月度次数限制；当前参战将领不能远程重装武器。最多处理当次威胁最高的两座城。

## 选择与筹备目标

距离较近的弱城优先；同样容易攻下时，保留按真实行军时间与目标国领地数量加权的随机性，大国仍更容易遭到不同国家施压。先粗略评估距离、城防、守军生命与战斗属性，再对少量候选精算地形行军时间。主角也计入强将防守。

从各城扣除原定留守名额后，挑选最多四名将领，高级将领先行。按原驻军顺序估算守将轮次、士兵库存、装备直接伤害和普通碰撞，检查是否能连续拿下初始城防对应轮数或清空守军。预测不预支 50% 城防降级的好运气，也不靠复制完整 NES 内核逐帧试打。

优先使用不需要牺牲将领的方案；若裸装预计出现战败，则尝试增加武器以减少损失与所需队伍，高防御轮攻至少预备有效装备。将领不足时先招募，只在招募门槛阻挡时升级扩充名额。人数和装备足够、资金不够时保留目标积蓄金币，不先零散派出准备不足的队伍。附近有更容易且现有资金能承担的目标时转攻该目标；当前最强四人编队也无法取胜时评估其他目标，不无限招募无法上场的第五人。

发动前统一检查整支队伍的武器费用、兵员费用及包含排队的粮草预算，资金充足后一起配齐并出发。使用现有城下排队规则逐将进场。进攻过程中电脑会使用武器，在安全武器耗尽且实际战况明显不利时考虑撤退。断粮后的旧营地优先回友城整备，撤退部队继续原路返回，不被经营逻辑改派。

这是一套新增的可调整策略评估，不是从 ROM 提取的原版国家 AI，也不保证每次预测都获胜：对方可能升级、招募、增援，战斗和撤退仍含随机性。

## 开销控制

- 各国平均每五秒决策一次，按国家错峰，一次固定逻辑帧最多处理一个国家。
- 每次只为当前国家建立驻军、归属和威胁快照；目标粗筛后最多三条候选路线做精算。
- 路线耗时按出发坐标、目标城与等级缓存，最多 256 条；城堡变化会使用新键，长期游戏不会无限增加缓存。
- 轮攻预测最多四名将领，使用算术估计，不逐帧模拟假想战斗；武器判断最多每半秒一次。
- 多张正式地图的回归测试检查错峰次数、路线计算数量、金币、兵员与英雄唯一性。模拟耗时是无渲染逻辑测试结果，不能当作整机画面帧率。

参数位于 `GameConfig`：`aiThreatDistance`、`aiMaximumRaidHeroes`、`aiTargetShortlist`、`aiTravelCacheSize`、`aiRaidRetrySeconds`、`aiWeaponDecisionSeconds`，原有粮草、工资和近邻／大国权重也继续生效。
