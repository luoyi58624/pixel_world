# 战役配置与当前规则

本文记录 2026-09-11 的新游戏规则。ROM 原始数据与反汇编结论仍以 `nes_heroes.md`、`nes_battle_algorithm.md` 等提取报告为准；本页中的经济、升级、AI 和平衡参数不是原版事实。

## 数值入口

| 文件 | 内容 |
| --- | --- |
| `assets/data/campaign_config.json5` | 可参与战役的国家（0–11）`initialGold`、`monthlyBaseIncome`，各地图城池的 `initialLevel` 和 `baseIncome` |
| `assets/data/heroes.json5` | 英雄顺序、身份、战斗、内政、生命上限、`morale`、`salary`、`nativeCountryId` |
| `assets/data/rom_weapons.json` | 武器价格、伤害、解锁年份、动画和初始库存 |
| `assets/data/game_config.json5` | 月份时长、收入、兵力、升级费用、年度城防上限、战斗倍率、行军和 AI 规则 |
| `lib/features/ai/config.dart` | 决策间隔、预算、集中进攻和极端召回阈值 |

修改开局数值后热重启，重新创建战役。英雄固定 ID 用于引用，数组顺序用于驻军展示，主角排首位；自动守城按驻軍名单从后向前出战。英雄JSON只保留 `id`、`name`、`type`、`maxHp`、`combat`、`morale`、`politics`、`salary`、`eggCapable`、`soldierLimit`、`nativeCountryId`；原版报酬、姓名编码和来源偏移由离线提取报告保存。41名原版将领的 `combat` 已还原；续玩时按历史受影响角色识别并纠正统一加3的遗留值，同步正在进行的战斗。回放和已结束战斗保留历史属性，扩展将领保持自定义配置。

## 城防升级

同月可以多次升级；每次必须有合法的本城主持将领，并支付费用。

| 当前年份 | 允许升级达到的最高等级 |
| --- | --- |
| 第一年 | 3 |
| 第二年 | 4 |
| 第三年及以后 | 5 |

这是升级限制，初始配置的四级、五级城池不会被降级。跨年立即解锁；敌我规则相同，AI 的连续升级候选和执行阶段均校验上限。达到当年上限时方块禁用，提示下一等级的开放年份。

基础费用数组为 `[30, 50, 100, 160]`，分别是一升二到四升五。实际费用为 `max(0, 基础费用 − 主持者内政)`，仍需足额现金，不允许赊账升级。升级不生成士兵、不消耗主持者，但每升一级增加5金币正常月产出；正在出征或交战的将领不能主持。中途升级也不增加已开打攻城战的迎战轮数。

## 全国金币与兵员

每60游戏秒进入下个月，12月之后跨年。每个仍有城池的国家分别结算：

`国家 monthlyBaseIncome + Σ(20 + (城池等级 − 1) × 5 + 本城收成调整) − 实际应付月俸`

国家保底配置在 `countries[].monthlyBaseIncome`，必须是10～30的整数，只按国家发一次：阿尔马国为10，其他国家暂设20，可逐国修改。旧配置未填写时默认20；无城国家不领取保底。这里的保底是收入的固定部分，不是净收入下限，城池负产出和费用可以抵扣它。

正式地图每城一级正常产出20，二至五级依次为25、30、35、40；自定义地图仍可通过城池 `baseIncome` 修改一级产出。本土与占领地同额，易主降为一级时相应降低正常产出。

**每座城每月独立抽取**：正常50%，不调整；丰收25%，随机增加5～30；欠收25%，随机减少5～30。增减幅度为包含两端的等概率整数，正常时不再抽幅度。同国可同时出现不同收成，不按全国合并成一次抽取。

欠收允许城池收入为负，也允许整国收入和国库为负。例如一级城欠收减30，城池收入为−10，会抵扣国家固定收入。月结日志保存每座城的等级、正常产出、收成、随机增减和实际收入，混合收成明确标注；存档保留已经发生的账单，不重新抽取。额外驻军费仍为0，工资和实际野外粮草照常收费。

全国储备上限：`开局实际登场将领数量 × 4 + 当前拥有的城池等级总和 × 4`。开局的英雄贡献只记录一次，招募、解雇、阵亡和转城不改变它；每级城防贡献四兵，失城和降级扣回对应贡献，无城后归零。例如三名开局将领加一级城为 16，升二级后为 20。

开局储备满编。旧 `initialReserveSoldiers`、`requiredGarrison` 字段只作输入兼容，不再控制正式开局兵力或固定留守人数。所有友城共用一份库存；每兵一金币，征兵方块每次最多购买十人，允许透支国库补兵，但不能超过全国储备容量。

出征或每轮守城开始时从全国库存领最多四兵，有多少领多少。外出英雄不能远程领兵。回城、守城结束归还生还兵员，超出上限的部分丢弃；升级和占城只增上限，不赠兵。战败士兵不会重新出现。

## 将领月俸与解雇

`nativeCountryId` 按第三张地图的实际初始归属绑定，但不再决定免薪。所有将领在本国或外国都按 JSON 的 `salary` 收费；`null` 表示没有专属国家。主角归属玩家国，当前月俸配置为5。

当前月俸为高级将领4～5、普通将领1～3，主角5；本次保留已有范围内的个人档位，只把低于4的高级将领提高到4。每位可单独改 JSON。签约立即支付首月月俸，当月月底不重复扣费，次月开始照常结算，没有额外签约费。历史费用不追扣；配置修改仍受存档资源指纹校验，不强行跨配置读取旧档。

解雇只返还 `内政` 对应的金币，停止后续月俸和粮草，进入共享回收池。主角及正在交战者不能解雇。解雇不降低兵力上限的开局英雄贡献。

## 招募名额与野外粮草

所有国家从第一游戏月即可招募将领，玩家与 AI 一致。不限制驻军人数、城池等级或月度次数，每次抽取花五金币。共享池包含尚未登场及已阵亡的非主角英雄，同一英雄只能处于在场、池中、待签约三者之一。

AI 每 4 游戏秒检查策略，每 10 秒整理资源补员。允许单将先攻前排、承担有限战损后补充，不再等待全队足以打穿整城；尚未实际出征的旧目标不会封锁其他进攻选项。其他城池存在未解决威胁时，安全城池仍可独立组织远征，本城留守与实际粮草支付约束继续生效。

前线、小国和受威胁城市保留实际守将，入城预约或未落地的招募不算守军。拥有至少三城、没有城战且敌城和可见敌军均不在警戒范围内的后方允许派空；按最快行军距离并留观察余量判断，执行前再核对敌情。主力优先出击，中等战力留守；高内政将领不用于消耗出击，低攻击内政将领可沿安全路线转移建设。紧急撤离仍要求明确来敌和有效友城，不能通过解雇派空城。

前线空城优先招募或从安全友城接防，常规补员只放在靠近进攻目标且可招募的友城，后方不反复抽将；出现实际威胁时启用本地防御招募。已有主力直接攻向敌城，后期多城国家不受单将45秒距离门槛阻挡，仍需支付完整路费。远近部队按抵达时间分批组织，不为凑队往返转驻。通用的闲兵前移已取消，仅保留必要接防、返程、撤离和明确的内政建设转移。

模拟结果逐国记录出征、占城、阵亡、签约、解雇、空城累计城秒、最长连续空城时间，以及主动派空/解雇空城事件。空城累计时间包含战损后的自然空城，主动空城还需按事件原因区分紧急撤离。

玩家抽中立即锁定，首月工资不足不能签约；关闭或切换城池窗口视为放弃，退回池中但不退抽取费。保持窗口时，候选保留到次月底，第三个月开始过期。NPC 预留抽取费及最高首月工资，抽中后立即签约。签约或放弃后可以继续抽取。

每名外出英雄每十秒扣一金币，扎营同价，月俸另计；改令不清除粮草零头。即使国库为负，行军、返程和战斗都继续，粮草仍逐笔全额扣除，不自动断粮扎营。负金币也可补充现有士兵；招募将领、升级城防仍须足额现金，不能透支。驻军人数及招募次数不限。AI补充现有兵力采用相同透支规则，不因此改变每将四兵或招将规模；普通经营仍参考工资和现金预算，避免无度承诺。

## 士气与攻城

士气读取独立 `morale` 属性，受伤不降低下一场的配置士气。`battleUseMorale` 控制是否启用士气，当前开启；`battleMoraleDrainPerSecond = 12.0`、`battleMoraleDrainRandomRange = 4.0` 表示每秒消耗8～16点。双方各自每60个战斗逻辑帧抽一次速度，逐帧累计扣除，小数跨秒保留，随机幅度为0时双方固定每秒扣12点。冲锋时每支付一点士气积累一点，单次士气攻击加成沿用24点上限。城防一至五级基础攻击分别增加2、4、6、10、15，守城开场士气额外增加5、10、15、20、25，总士气不截断，红条最多显示100；超额在开战时即加入第一轮积累，正常消耗同时进行，首次碰撞合并结算后清零超额。野战没有城防加成。城防攻击不增加冲锋速度，也不参与击退差值，`cityDefenseRecoilScale = 0.0`。全局击退差倍率0.25、撞墙伤害倍率0.5。配置位于 `GameConfig`，复现方式见 [战斗平衡验收](combat_balance.md)。

连续攻城的城防加成按剩余轮数递减。赢满开场城防等级对应的轮数或清空守将即可占城，易主重置一级。未占领时，整场结束按每个非互刺胜轮必定降一级，最低一级。攻城失败不降低进攻方出发城等级。

所有城战结束后生还将领恢复 HP，兵损保留。撤退成功率满血满兵为 90%，每少一兵及每累计损失 25% 英雄生命各减十个百分点；守城方不能撤退。

## 灭国战利品

最后一城易主时清空败国国库，胜国不继承金币或债务；部分失城不转移国库。

## 国家策略

资源每十秒整理，策略每四秒检查，国境预警可立即请求防守。国境按地形到城池的行军成本划分；边界开关仅控制绘制，不影响国防判断。

驻城将领不再主动出城截击，已经在野外的部队仍可就近截击。

召回远征是最后手段：必须有明确逼近城池的来敌，本地补兵、升级、招募或截击无法解决，连乐观的守城评估也显著落后，并且实际地形路线来得及。原地扎营、只是进入领土、普通整备预算不足不能打断城下主力。行军分段的短暂停靠继续原任务。无法及时赶回就保持远征。

按近处弱国、仇恨与国力选目标，主力按当前生命、兵员和目标城防评估进攻。后期结合强将人数、资金与抵达时间组织连续轮攻；安全后方部队前移，不机械固定留守。
