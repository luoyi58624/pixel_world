# 战役配置与当前规则

本文记录 2026-09-11 的新游戏规则。ROM 原始数据与反汇编结论仍以 `nes_heroes.md`、`nes_battle_algorithm.md` 等提取报告为准；本页中的经济、升级、AI 和平衡参数不是原版事实。

## 数值入口

| 文件 | 内容 |
| --- | --- |
| `assets/data/campaign_config.json` | 各国 `initialGold`、各地图城池的 `initialLevel` 和 `baseIncome` |
| `assets/data/rom_heroes.json` | 英雄顺序、身份、战斗、内政、生命上限、`morale`、`salary`、`nativeCountryId` |
| `assets/data/rom_weapons.json` | 武器价格、伤害、解锁年份、动画和初始库存 |
| `lib/core/config/game_config.dart` | 月份时长、收入、兵力、升级费用、年度城防上限、战斗倍率 |
| `lib/features/ai/config.dart` | 决策间隔、预算、集中进攻和极端召回阈值 |

修改开局数值后热重启，重新创建战役。英雄固定 ID 用于引用，数组顺序用于驻军展示，主角排首位；自动守城按驻軍名单从后向前出战。保留 `romCombat`、`romSalary` 及来源偏移用于对照。

## 城防升级

同月可以多次升级；每次必须有合法的本城主持将领，并支付费用。

| 当前年份 | 允许升级达到的最高等级 |
| --- | --- |
| 第一年 | 3 |
| 第二年 | 4 |
| 第三年及以后 | 5 |

这是升级限制，初始配置的四级、五级城池不会被降级。跨年立即解锁；敌我规则相同，AI 的连续升级候选和执行阶段均校验上限。达到当年上限时方块禁用，提示下一等级的开放年份。

基础费用数组为 `[30, 60, 100, 160]`，分别是一升二到四升五。实际费用为 `max(0, 基础费用 − 主持者内政)`。升级不生成士兵，不消耗主持者；正在出征或交战的将领不能主持。中途升级也不增加已开打攻城战的迎战轮数。

## 全国金币与兵员

每 60 游戏秒进入下个月，12 月之后跨年。每个仍有城池的国家月收入为：

`30 + Σ(城市 baseIncome + (等级 − 1) × 5) + 收成调整 − 实际应付月俸`

50% 正常收成、25% 欠收、25% 丰收。欠收全国一次减 30，丰收全国一次加 30。占领的外国城池正常计算，不再减半。月结和灭国收益进入国家事件日志；城池面板不再单列经济区。国库最低为零。

全国储备上限：`开局实际登场将领数量 × 4 + 当前拥有的城池等级总和 × 4`。开局的英雄贡献只记录一次，招募、解雇、阵亡和转城不改变它；每级城防贡献四兵，失城和降级扣回对应贡献，无城后归零。例如三名开局将领加一级城为 16，升二级后为 20。

开局储备满编。旧 `initialReserveSoldiers`、`requiredGarrison` 字段只作输入兼容，不再控制正式开局兵力或固定留守人数。所有友城共用一份库存；每兵一金币，征兵方块每次最多购买十人，有钱可随时补充。

出征或每轮守城开始时从全国库存领最多四兵，有多少领多少。外出英雄不能远程领兵。回城、守城结束归还生还兵员，超出上限的部分丢弃；升级和占城只增上限，不赠兵。战败士兵不会重新出现。

## 将领月俸与解雇

`nativeCountryId` 按第三张地图的实际初始归属绑定。专属将领在本国免薪，在其他国家按 JSON 的 `salary` 收费；`null` 表示没有专属国家。主角归属玩家国。

当前外聘月俸：高级将领 8～10 金币；普通将领按战斗属性为 2～7 金币。每位可单独改 JSON。签约立即支付首月月俸，当月月底不重复扣费，次月开始照常结算。高级将领不再额外支付十金币签约费。

解雇只返还 `内政` 对应的金币，停止后续月俸和粮草，进入共享回收池。主角及正在交战者不能解雇。解雇不降低兵力上限的开局英雄贡献。

## 招募名额与野外粮草

招募不限制驻军人数、城池等级或月度次数，每次抽取花五金币。共享池包含尚未登场及已阵亡的非主角英雄，同一英雄只能处于在场、池中、待签约三者之一。

玩家抽中立即锁定，首月工资不足不能签约；关闭或切换城池窗口视为放弃，退回池中但不退抽取费。保持窗口时，候选保留到次月底，第三个月开始过期。NPC 预留抽取费及最高首月工资，抽中后立即签约。签约或放弃后可以继续抽取。

每名外出英雄每十秒扣一金币，扎营每二十秒扣一金币，月俸另计；改令不清除粮草零头。钱用尽时原地扎营，交战中的部队先打完当前战斗。AI 常规招聘将月俸控制在正常收入的 50% 内，防守紧急招聘可使用更高预算；这是 AI 自主预算，不限制玩家。

## 武器、士气与攻城

武器商店位于右下角，国家库存按种类堆叠、无数量上限，出征最多带三件，回城卸回库存。守城方不能使用。当前十二种武器，已移除台风、强击手、死枪；按价格顺序每行三种，第一年开放第一行，之后每年增加一行。

每名参战英雄对每个对手最多自动使用一件武器，换守将后才获得下一次机会。原始素材与脚本用于动画；新游戏不提供手动释放按钮。

士气读取独立 `morale` 属性（0～100），受伤不降低下一场的配置士气。普通拼杀使用 NES 内核和新游戏的平衡倍率；当前城防每级加一点整队基础攻击，不增加士气。击退差值倍率 0.25，撞墙伤害倍率 0.5，避免少一兵后立刻持续受压。

连续攻城的城防加成按剩余轮数递减。赢满开场城防等级对应的轮数或清空守将即可占城，易主重置一级。未占领时，整场结束按每个胜轮独立 80% 几率降一级，最低一级。攻城失败不降低进攻方出发城等级。

所有城战结束后生还将领恢复 HP，兵损保留。撤退成功率满血满兵为 90%，每少一兵及每累计损失 25% 英雄生命各减十个百分点；守城方不能撤退。

## 灭国战利品

最后一城易主时，胜国一次性接收败国剩余金币及国家武器库。先清空败国，再合并胜国库存，双方分别记录日志。部分失城不转移国库；仍在交战的外出将领携带物品不当作国家仓库重复结算。

## 国家策略

资源每三十秒整理，防守每八秒扫描，最后才执行进攻。国境按地图地形到城池的行军成本划分；设置中的边界开关仅控制绘制，不影响国防判断。

出城消耗截击同时要求：当前城有余将、预计直接守城处于劣势、可配备当前最强的已解锁或库存武器。优先派实际攻击力低的将领（默认不高于八），保留高攻击守将；没有能兑现的削弱效果或赶不到接敌点，不派兵送死。

召回远征是最后手段：必须有明确逼近城池的来敌，本地补兵、升级、招募或截击无法解决，连乐观的守城评估也显著落后，并且实际地形路线来得及。原地扎营、只是进入领土、普通整备预算不足不能打断城下主力。行军分段的短暂停靠继续原任务。无法及时赶回就保持远征。

首年集中一条主攻战线，优先近处弱国，结合仇恨与国力。攻下一城后继续针对同国剩余城池，目标灭亡后再换国。后期只有明显优势才分兵，轮攻编队同时核算守军、兵器、兵员、粮草和抵达时间差。
