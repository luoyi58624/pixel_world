# 战斗平衡验收

2026-09-11 定版：守城应有优势，士气在冲锋中随机蓄力，兵员死亡立即失去攻击贡献；不能依靠城防稳定地把同级将领压到墙边。

## 当前数值

| 参数 | 数值 |
|---|---|
| 每名存活士兵 | 20生命、1攻击 |
| 一至五级城防攻击 | 1、2、3、4、5 |
| 城防参与击退的比例 | 25% |
| 城防对冲锋速度、士气的额外加成 | 0 |
| 全局击退强度差倍率 | 0.25 |
| 撞墙伤害倍率 | 0.5 |
| 随机蓄力判定间隔 | 12帧，即0.2秒 |
| 每次蓄力成功率 | 25% + floor(剩余士气/2)%，士气为0时不能蓄力 |
| 每次成功消耗与积累 | 消耗1士气，均匀随机积累1到4点 |
| 碰撞时的士气贡献 | 积累为0时为0，否则 min(4, floor(积累/4)+1) × 6，最高24 |

双方使用相同判定时刻，各自独立抽取；只在向敌方冲锋时判定，碰撞后清空积累。所有抽取复用战斗的可存档随机状态，不依赖真实时间或界面刷新率。恢复旧战斗存档时保留伤势与士气，并采用当前城防和存活兵员攻击。

## 独立种子验收

复现：`dart run tool/audit_combat_balance.dart --samples 128 --seed 20260912`。工具只用于离线对照，运行时AI不得读取样本或试打。

四类同属性对战的攻击/生命/士气分别为10/50/60、12/65/75、15/95/50、18/95/100，双方均为四兵。每类每级128场，每级合计512场。计数为单轮交战的结果，平局单列，不并入任意一方胜率。

| 城防等级 | 进攻胜 | 守城胜 | 平局 | 守城胜率 |
|---|---:|---:|---:|---:|
| 1 | 230 | 240 | 42 | 46.9% |
| 2 | 176 | 277 | 59 | 54.1% |
| 3 | 152 | 297 | 63 | 58.0% |
| 4 | 100 | 354 | 58 | 69.1% |
| 5 | 74 | 393 | 45 | 76.8% |

五级城四类将领各自都有攻方胜例，攻方胜率约13%到16%，没有全样本碾压。所有场次均在300秒模拟上限前结束。无城防对照为263胜、184负、65平，仍有进攻侧偏向，本轮不声称左右完全对称。

额外7组对照每组128场，共896场；与上述含无城防的3072场合计3968场。攻击15、生命95时，士气100进攻士气50的结果为121胜、4负、3平；反向为10胜、108负、10平，士气有明显影响但不保证胜利。五级城开场遭受80点武器伤害、四兵全灭后，进攻方127胜1负；清兵武器是强力克制手段。

这些数字不是整座城的占领概率，也不是完整国家对局胜率。高等级城保留更多连续守城轮数，武器不会每轮免费补充；兵损、将领差距、前序交战和资源成本会改变实际战役结果。原始批量输出保存在忽略目录 `build/national_ai/combat_balance/`，不作为运行时数据提交。
