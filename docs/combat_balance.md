# 战斗平衡验收

## 目标与条件

同条件野战胜率约50%；无武器进攻一级城约30%、二级城低于5%、三级及以上不出现进攻胜例。基准双方战斗力15、生命95、基础士气50、四名满血士兵。所有武器属性和价格保持原值，包括炮的25金币、80伤害；本轮没有增加减伤或强制胜负规则。

## 当前参数

| 参数 | 数值 |
|---|---|
| 一至五级城防攻击 | 1、3、12、14、16 |
| 一至五级守城开场士气 | +5、+25、+50、+50、+50，叠加后封顶100 |
| 全局击退差倍率 | 0.5 |
| 城防参与击退比例 | 0.5 |
| 撞墙伤害倍率 | 0.5 |
| 每名存活士兵 | 20生命、1攻击，阵亡立即扣除攻击 |
| 士气倍率 / 蓄力间隔 | 6倍、12帧（0.2秒） |
| 野战将领攻击倍率 | 草地90%、河流70%、山地50%，双方相同 |

纠正了击退取整偏差：先对带符号的强度差取整，再加回基准值。旧写法先加正基准再取整，会让同样大小的正负半点差得到不对称结果。保留原有冲锋、随机蓄力和碰撞流程，不通过额外抽签或写死胜负来匹配胜率。

所有场次均正常结束，没有超时。零胜例是这组测试的观测结果，不用有限样本冒充所有随机种子的数学证明。

回归测试 `test/features/battle/balance_targets_test.dart` 使用另一个种子20260923，每项1024场，检查野战45%～55%、一级城25%～35%、二级城低于5%，以及三级到五级零进攻胜例。原版6502对照仍保留，存档恢复必须继续产生相同随机结果，AI读取同一份城防参数。

这些都是同属性、无武器的单轮结果，不代表异属性、携带武器或整座城的占领概率。批量输出放在忽略目录 `build/national_ai/combat_balance/`，仅用于离线验收，不允许运行时AI读取或试打。
