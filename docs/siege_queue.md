# 攻城队列与守将顺序

本规则是新游戏的战役调度，普通拼杀仍使用现有 NES 战斗内核。

## 统一英雄名单

所有国家使用 `rom_heroes.json` 数组顺序展示驻军，主角固定第一；当前为主角、泽拉斯、亚彭龙、威拉斯、波塞伊，随后为其余高级与普通将领。原 ROM 编号继续关联身份和资源，不等于展示顺序。迎战从名单末位向前选择，主角最后；出征、阵亡或正在交战者跳过。招募、进驻或回城后回到对应优先级位置。

只在开战或下一位守将上场时读取名单，当前交战者不会被后来进驻的英雄替换。排序由 `CampaignHero.compareRosterOrder` 统一处理，守将不再使用随机源；招募抽取和 NPC 进攻目标仍按既有规则随机决定。

## 排队与野战

- 每座城同时只接待一支进攻部队，连续守将和换人间隙都保留名额。同一国家的不同城市各自处理攻城。
- 其他部队到达城下便停止，按实际抵达先后接战；同一固定时间步内同时抵达时按英雄编号稳定排序，不以派兵顺序插队。
- 等待期间仍参加野外遭遇检测。不同国家将领相遇便在城外决战，同国不交战；当前城战和野战参与者不会被第二场战斗抢走。
- 队首正在野战时，后续队伍可以先进入攻城。胜者保留伤势、原目标与原抵达顺序，败者移除。主动改道或扎营会退出队列，再来需要重新排队。
- 连续攻城期间只降低下一轮的临时加成，不提前降低真实城防。未攻下的整场结束后，每个已胜轮次独立判定 50% 降级；赢满初始城防等级对应的轮数即可占领并重置一级。城堡实际升级或战后降级时，等待者保持原位，轮到后再步行到新接触点，调整期间后面的部队继续等待。
- 目标变为友城后按正常进驻处理；无存活驻军且没有正在进行的攻城时，可以占领。换守将间隙剩余驻军全部离城也会结束攻城并结算占领，不会卡住。

## 验证

`test/features/battle/siege_queue_test.dart` 覆盖原名单顺序、候选过滤、交战中不换将、到达顺序、换人占位、多城并行、等待遭遇、胜者恢复队列、败者清除、主动退出、空城结算及城堡尺寸变化。
